# Daybell

School and volume photography software for studios in the US and Canada. Everything GotPhoto does, for 3% of
product sales.

Start with [CLAUDE.md](CLAUDE.md) for the rules and repo map, and `docs/adr/` for the main technical choices.

```sh
pnpm install
pnpm dev     # web app on http://localhost:3000
pnpm check   # lint, types, tests, build
```
